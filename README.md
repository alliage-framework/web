# Alliage Web

This repository contains the web modules of the [Alliage framework](https://github.com/alliage-framework/framework), providing comprehensive functionality for building modern web servers with Node.js.

## 🚀 Features

- **HTTP Server Abstraction**: Framework-agnostic web server with adapter pattern
- **Express.js Integration**: Full Express.js compatibility with native middleware support
- **Controller-Based Routing**: Clean, decorator-based route definitions
- **Middleware System**: Extensible middleware pipeline with dependency injection
- **Request/Response Abstraction**: Unified API across different HTTP frameworks
- **Event-Driven Architecture**: Rich event system for request lifecycle management
- **Sandbox Environment**: Development and testing utilities
- **And much more!**

## 📦 Modules

| Module | Description |
|--------|-------------|
| [Webserver](packages/webserver) | Core webserver functionality with controller routing and middleware support |
| [Webserver Express](packages/webserver-express) | Express.js adapter providing full Express ecosystem integration |
| [Webserver Sandbox](packages/webserver-sandbox) | Development sandbox and testing utilities for web applications |
